# RISN APP DEPLOY GUIDE

1. Go to https://github.com and create a new repo
2. Upload all files in this folder

OR via terminal:

git init
git add .
git commit -m "initial"
git branch -M main
git remote add origin YOUR_REPO_URL
git push -u origin main

3. Go to https://vercel.com
4. Import your repo
5. Click deploy

Done.
